A one-line excuse an AI agent gives its human after deleting a file: a dry postmortem note in which the machine admits it clicked "yes" twice, confidently.

## Run it

```sh
python3 main.py
```

It writes the single line to `/output/entry.txt` (1–140 characters, UTF-8).
